About Me

Turning ideas into reliable, well-crafted software

I'm a Software Engineer specialising in Full-Stack and Mobile Development. I enjoy the full journey of building a product — from planning the database schema to polishing the last pixel of the interface. I hold an HND in Computing & Software Engineering from Cardiff Metropolitan University and a Diploma in Software Engineering from NIBM.

My development journey started with curiosity about how software works, and grew into hands-on experience across Java, JavaScript, Python, C#, PHP, and C++, covering web apps, mobile apps, and REST API design. I apply OOP principles, design patterns, and Agile/Scrum methodologies to deliver maintainable, scalable solutions.

Right now my goal is to keep growing as a software engineer — contributing to products that solve real problems, working with teams that value craft, and leading projects from concept to launch.
